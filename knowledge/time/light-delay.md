# Query

"When could observer B first have observed event A?" Solved as the intersection of A's future light cone with B's worldline.

This is separate from simultaneity, which is defined by GCT; see [timeline and frames](/time/timeline-and-frames.md). Useful for sci-fi plotting ("news of the coronation reaches the colony on…").
